# دفتر تصمیم‌ها (اصل XI)

این فایل تصمیم‌های **تصویب‌شده** را از **پیشنهادها** و **موارد نیازمند تأیید مالک پروژه** جدا
نگه می‌دارد. هیچ موردی در بخش «نیازمند تصمیم» نباید به‌عنوان مصوب تفسیر شود.

## ۴. یافته‌های محیطی ثبت‌شده (نه تصمیم)

- نقش واقعی PostgreSQL برنامه در محیط توسعه: `recruitment` با `rolsuper=True`؛ روی
  `audit_auditevent` مجوزهای `DELETE, UPDATE, TRUNCATE` دارد. این با ادعای `apps/audit/models.py:9-11`
  در تضاد است و در `docs/operations/secrets.md` ثبت شد.
- توزیع مهاجرت قدیمی `0002_job_status_graph`: پوشه در هیچ مخزن git ردیابی نمی‌شود؛ اما این
  «عدم انتشار» را اثبات نمی‌کند (بدون تاریخچه، بدون رجیستری بسته، بدون دسترسی به سرور هدف).
  وضعیت: **ناشناخته**، نه «هرگز توزیع نشده».
- **تست‌های Playwright در محیط محلی این اجرا نیاز به `DJANGO_ALLOW_ASYNC_UNSAFE=1` دارند**: API
  همزمان (sync) Playwright حلقهٔ رویداد asyncio را با `greenlet` روی همان نخ اصلی (نه نخ جدا)
  پیاده‌سازی می‌کند؛ `asyncio.get_running_loop()` آن را «در حال اجرا» گزارش می‌دهد حتی وقتی فقط
  معلق است، و بررسی ایمنی Django (`SynchronousOnlyOperation`) این را به‌اشتباه ناسازگار تشخیص
  می‌دهد. این env var فقط موقع اجرای تست تنظیم شود، هرگز در dev/prod (که اصلاً Playwright اجرا
  نمی‌شود). همچنین نسخهٔ نصب‌شدهٔ `pytest-playwright` باید با پین `requirements/dev.txt` (۰.۵.۲)
  یکسان بماند — محیط یک‌بار بدون دلیل مشخص به ۰.۱۰.۰ رانده بود.
